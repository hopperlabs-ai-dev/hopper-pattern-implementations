# Hopper Pattern Implementations

Portable, runnable reproductions and reference implementations for governed
engineering ideas. This repository owns executable truth; a consuming pattern
library owns curation, evidence, graph relationships, and adoption decisions.

## Try it

```bash
npm install
npm run quickstart
npm run demo
```

Open `http://127.0.0.1:47620`. The demo is deterministic, loopback-only, uses
fixed fixtures, and performs no network access.

## Included in 0.1.0

- Faithful, explicitly bounded reproduction of the Code as Agent Harness paper.
- Generalized executable-stateful-harness POC and production reference.
- POC and production architecture diagrams as portable SVG.
- Real execution demo with plan, checkpoint, verification, and receipts.
- Manifest, conformance, and release compiler contracts.

The source reproduction records what is supported by the paper and what is an
engineering interpretation. It is not presented as the authors' official code.
